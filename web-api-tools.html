SMART CONTROL

How Sadeeq decides

01 · Scope first

The bot's Instructions and Bot Rules remain the authority. An unrelated question cannot trigger a tool.

02 · Freshness check

Current or frequently changing information can use an enabled tool when it fits the bot's scope.

03 · Validate before answer

Tool results are treated as evidence, checked for relevance, and never allowed to override the bot's rules.

04 · Secure execution

API credentials stay server-side. Tool access is enforced by the backend, not just the browser UI.
